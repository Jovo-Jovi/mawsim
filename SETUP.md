## 1. Cursor key for the builder (one or two accounts)

Names: `CURSOR_API_KEY`, `CURSOR_API_KEY_2`

1. cursor.com → Dashboard → Integrations → API Keys → create a key named devos.
2. GitHub → this repository → Settings → Secrets and variables → Actions → New repository secret `CURSOR_API_KEY`, paste the key.
3. Optional second account (PR-29): its key as `CURSOR_API_KEY_2`. A run then switches to it when the first reaches its usage limit.

```
gh secret set CURSOR_API_KEY --repo Jovo-Jovi/mawsim
gh secret set CURSOR_API_KEY_2 --repo Jovo-Jovi/mawsim
```

## 2. Claude credential for the reviewer (one or two accounts)

1. On your computer run `claude setup-token` and sign in with your Claude plan.
2. Add the token as the repository secret `CLAUDE_CODE_OAUTH_TOKEN` (or an API key as `ANTHROPIC_API_KEY`).
3. Optional second account (PR-29): `CLAUDE_CODE_OAUTH_TOKEN_2` (or `ANTHROPIC_API_KEY_2`). A review then switches to it when the first reaches its usage limit.

```

gh secret set ANTHROPIC_API_KEY --repo Jovo-Jovi/mawsim

gh secret set ANTHROPIC_API_KEY_2 --repo Jovo-Jovi/mawsim
```
