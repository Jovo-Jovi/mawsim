### Notes for the reviewer
- Sentence patterns, chosen so each language reads on its own. English `seasonRange` is `{from} – {to}` (en dash, U+2013) and `seasonList` is `{earlier}, {later}`, so mango is "In season: July – October" and a split is "In season: January – February, May". Arabic `seasonRange` is `من {from} إلى {to}` and `seasonList` is `{earlier}، {later}` (Arabic comma), so mango is "في الموسم: من يوليو إلى أكتوبر" and orange is "في الموسم: من ديسمبر إلى أبريل". A single month is the name alone ("In season: June"), not "June – June". The hidden cell text uses the fence's English form "July, in season"; Arabic uses an Arabic comma ("يوليو، في الموسم") so the phrase is not Latin punctuation inside Arabic.
- Kind labels match the design-system chips: Fruit, Vegetables, Leafy greens / فاكهة، خضار، ورقيات. Arabic month names are the Egyptian set (يناير … ديسمبر). Short labels are three letters (ينا، فبر، مار، أبر، ماي، يون، يول، أغس، سبت، أكت، نوف، ديس) so they can sit under a cell at 390. "سبت" is the September abbreviation; the accessible name is the full "سبتمبر".
- The "This month" tag is the lemon current-month tag (`--color-highlight` / `--color-on-highlight`). It sits under the twelve cells. Slots 1–3 align to the inline start and 10–12 to the inline end so the label stays inside the bar; the accent outline is what marks the cell. There is no page yet, so 390 was not opened in a browser. Stage 2 captures it.
- Contrast, WCAG 2.2 relative luminance, same method as T05. Kind fills are empty spans (`aria-hidden`); text uses ink, ink-muted, accent, or on-highlight.
