1. **The manifest loader**, in `src/modules/produce/photos.ts`. It is the only non-test file in `src/` that names
   `content/photos.json` (relative import). It exports:
   - `interface ProducePhotoRow`, all fields `readonly`, named exactly as `CONTENT_MODEL.md` §5: `key`, `file`, `width`,
     `height`, `alt_en`, `alt_ar`, `author`, `source_url`, `licence`, `licence_url`, `credit_required`;
   - `parsePhotoRows(raw: unknown, context: { slugs: readonly string[]; fileExists: (file: string) => boolean }):
     readonly ProducePhotoRow[]`. It checks every §5 rule: an array; each row an object with the eleven fields of the
     right type and no extra key copied; `key` is `"hero"` or one of `context.slugs`, and unique; `file` starts with
     `/photos/`, ends `.avif`, `.webp` or `.jpg`, has no `..`, and `fileExists(file)` is true; `width` and `height` are
     positive integers, with width at least 1600 for `hero` and 1200 for a produce key; `alt_en`, `alt_ar`, `author` and
     `licence` are non-empty; `source_url` and `licence_url` begin `https://`. Errors are `Error` with a fixed message
     naming the 0-based row index and the rule (for example `photo row 0: file does not exist in public`), never a field's
     value. Not an array: `photo rows: not an array`;
   - `getProducePhoto(slug: string): ProducePhotoRow | undefined`, `getHeroPhoto(): ProducePhotoRow | undefined` and
     `listPhotoCredits(): readonly ProducePhotoRow[]` (the rows with `credit_required` true, in file order).
   The module parses once at load, through `parsePhotoRows`, with `slugs` from `listProduce()` and a `fileExists` that
   checks `public` + the file with `node:fs` `existsSync`, resolved from `process.cwd()`. Reading the file system at load is
   build-time only here; add no `"use client"`, no `server-only` and no dependency. With today's `[]` it returns nothing.
2. **The photo frame**, in `src/modules/produce/ProducePhoto.tsx` with `ProducePhoto.module.css`, plus a small
   `SeasonRing.tsx` / `SeasonRing.module.css` for the fallback. `ProducePhoto` is pure over props:
   `{ produce: Produce; photo: ProducePhotoRow | undefined; locale: Locale; slot: "card" | "page" | "hero"; priority?: boolean }`.
   The caller supplies `photo` from `getProducePhoto` or `getHeroPhoto`. It is a server component.
   - **Frame.** One wrapper with a fixed `aspect-ratio` per slot (`DESIGN_SYSTEM.md` §6): card `4 / 3`; page `3 / 2`, and
     `4 / 3` below 40rem; hero `4 / 5` below 40rem, `5 / 4` from 40rem. Radius `--radius-lg`, `overflow: hidden`, a
     `--color-hairline` border. The size is reserved whether or not the image has loaded.
   - **Photo branch.** `next/image` with the row's `file` as `src`, its `width` and `height`, `alt` from `alt_en` or
     `alt_ar` by `locale`, `object-fit: cover`, `sizes` per slot (card `(min-width: 64rem) 25vw, 50vw`; page
     `(min-width: 64rem) 50vw, 100vw`; hero `100vw`), and `priority` only when the prop is true (`loading` lazy
     otherwise). No `unoptimized`, no remote host, no `images` key in `next.config.ts`.
   - **Fallback branch** (no row). The same frame holds a tile on the produce's kind colour (`--color-kind-fruit`,
     `--color-kind-vegetable`, `--color-kind-leafy`, through a `data-kind` attribute that the stylesheet selects), the
     produce's name in the page's locale as visible text with its counter-name in the other language carrying its own
     `lang`, and a decorative `SeasonRing`. The ring is twelve arcs in inline SVG: in-season months filled, the others a track;
     `aria-hidden="true"`, no motion. Direction follows `dir` (clockwise in `ltr`, counter-clockwise in `rtl`) through the
     page's `dir`, not a hardcoded value. There is no `<img>` in the fallback, so no broken-image box. The fallback adds no
     catalogue string: it renders only produce data. Its text equivalent is the page's job (T06, T07).
   - CSS Modules over tokens only: no raw colour, size or duration (`guard:design`), logical properties only, no animation.
     Text on the tile meets 4.5:1 against its kind colour in both themes: if a token pair fails, use `--color-surface` or
     `--color-ink` as the pair needs, and say which in the report.
3. **Public entry.** `src/modules/produce/index.ts` additionally exports `ProducePhoto`, `getProducePhoto`, `getHeroPhoto`,
   `listPhotoCredits` and the type `ProducePhotoRow`. Nothing else is added.
