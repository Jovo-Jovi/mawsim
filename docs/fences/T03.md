inline start and the language link at the inline end, set in IBM Plex Sans Arabic. `home-en` is the LTR adaptation in Inter. The

page is not captured, because the runner counts a 404 as a failed request. Done-when 3 and 11 prove it. The global not-found
page uses the same `PageShell` as the segment not-found, so it looks the same.
