inside its card at every width from 320 to 1280 in both locales, for all ten rows of `content/produce.json`: no glyph past the card's border,
no clipping, no ellipsis, and no break inside a word (T07-a1). The name may step down in size with the card's inline size (a container-relative
size on the existing `container-type: inline-size`), never below `--text-sm`. Other card text, the tile and the grid are unchanged.

Both themes: every text pair passes §2 contrast. Logical properties only; no horizontal page scroll at 320–1280 (UA-15).
