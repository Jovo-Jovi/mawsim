### Design specification

- States: `home-ar` · `home-en` · `home-scene-en`
- Criteria: `UA-01` · `UA-02` · `UA-03` · `UA-04` · `UA-05` · `UA-06` · `UA-07` · `UA-08` · `UA-09` · `UA-10` · `UA-11` · `UA-12`

`DESIGN_SYSTEM.md` §13 is the specification; this fence names the files and rules, it does not restate the artwork.

1. **`HeroScenePoster`** (`HeroScenePoster.tsx`, server-renderable, no `"use client"`): an inline SVG of five to seven
   stylised produce (mango, orange, tomato, date cluster, molokhia leaf) in the kind colours as tokens (`var(--color-…)`
   on `fill`), `aria-hidden` and `focusable="false"` (decorative; the dial and the cards carry the information), no text,
   no `<script>`, no inline `style`. It fills the frame and is the whole first-HTML content of the frame.
2. **Frame** (`HeroSceneFrame.tsx`, `"use client"`, the module's only client file besides `HeroScene.tsx`): renders one
   `div[data-hero-scene]` of fixed size from new tokens (a `--scene-size` per breakpoint, in `tokens.css`, one row each in
   `DESIGN_SYSTEM.md` §2; no other token) holding the poster. The server HTML is the frame with the poster only, so the
   first render equals the server HTML. After mount, one `useEffect` asks the pure `scene-mode.ts` whether to run the scene.
   It runs the scene only when none of these holds: reduced motion, no WebGL (a throwaway canvas `getContext("webgl2")` or
   `"webgl"` returns null), a viewport narrower than 22.5rem (matchMedia on the token's value, not a literal), or a
   low-power device (`navigator.hardwareConcurrency <= 2` or `navigator.connection.saveData`). Then it loads `HeroScene`
   through `next/dynamic` with `ssr: false` so it is its own chunk, and the scene's canvas sits above the poster in the same
   box (position absolute, no size change). A reduced-motion change or a `visibilitychange` while mounted must not throw.
3. **Scene** (`HeroScene.tsx`, `"use client"`): `three` and `@react-three/fiber`, geometry built in code from simple
   primitives, no model file, no texture image, no `fetch`, no `useLoader`, transparent background, one warm light from one
   side, `frameloop="demand"` driven by one `requestAnimationFrame` loop of the scene's own that turns the group about the
   vertical axis once per `--scene-turn` (48s, read from the computed style once, never a literal). It pauses when the frame
   is off-screen (one `IntersectionObserver`) and when `document.hidden`, and disposes geometry, materials and the renderer on
   unmount. Mirroring in `rtl` is not required (it is a turntable). `dpr` capped at 2.
4. **Control**: a `<button type="button" aria-pressed>` inside the frame at its inline-end bottom corner, label from the
   catalogues (new keys `home.sceneLabel`, `home.scenePause`, `home.scenePlay`, identical in `en` and `ar`; the pressed
   state names the action, the label stays the same), `--target-min`, the focus ring of §9, no raw colour. It exists only
   while the scene runs; the still has no button (§13). Pressing it stops and resumes the turn; `aria-pressed` follows.
5. **Layout** (stage 2): in `Hero.tsx` and `Hero.module.css` the frame sits beside the dial at its inline end at 1280 and
   below the dial at 390, never over the headline or the hero image's subject, logical properties only. Layout shift 0 with
   the poster, the canvas and the paused scene (the same box).
6. **Boundary**: no network call (the scene needs none), no CSP change (`next.config.ts` is not in Paths; `script-src`
   stays as is, so the scene must run without `unsafe-eval` and `unsafe-inline` beyond what is there), no cookie, storage or
   telemetry. The device checks read nothing out of the browser and store nothing (OD-10 §4).
7. **Captures**: `home-scene-en` hovers the frame, not the button: under reduced motion the still has no button (§13), and the
   reduced-motion twin repeats the action, so a `click button[aria-pressed]` would fail there. The button is proved by the
   e2e. Say in the report which branch the capture browser took (scene or poster) and why. If it took the poster only, say so;
   do not add a URL switch, a flag or a test hook to force the scene.
