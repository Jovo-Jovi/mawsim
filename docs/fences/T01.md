### Stage 2 — Server, errors, health and evidence tools

Files: `src/lib/logger.ts`, `src/lib/logger.test.ts`, `src/instrumentation.ts`, `src/app/error.tsx`,
`src/app/global-error.tsx`, `src/app/api/health/route.ts`, `src/app/api/health/route.test.ts`, `package.json`.
Proves Done-when 1, 3, 4, 5, 7, 10 and runs every Done-when command.

5. **Logger.** Add `pino` (dependency). `src/lib/logger.ts` exports `createLogger(destination?)` and
   `logger = createLogger()`: JSON lines, `level` from `LOG_LEVEL` (default `info`), `base: { app: "mawsim" }`.
   It is imported only from server files (a convention: no `server-only` package, so Vitest can import it). No IP,
   user agent, cookie, header or body is ever logged (`docs/STACK.md` §6). No `console.*` anywhere in `src/`.
6. **Errors and health.** `src/instrumentation.ts` exports `onRequestError` that logs
   `{ event: "request.error", routePath, routeType, err }` through `logger` (import the logger only when
   `process.env.NEXT_RUNTIME === "nodejs"`). `src/app/error.tsx` and `src/app/global-error.tsx` (client components)
   show `error.title` and a retry `<button>` (`error.retry`) from the default-locale (`ar`) catalogue, never `error.message` or a
   stack; `global-error.tsx` renders `<html lang={defaultLocale} dir={directionOf(defaultLocale)}>`, never a literal.
   `src/app/api/health/route.ts`: `GET` takes no input, reads no header or cookie, returns `200 { "status": "ok" }`;
   on a thrown error it logs `{ event: "health.error", err }` and returns `500 { "status": "error" }`. It is the only
   `route.ts` (zone `health`, OD-05). Add dev dependencies `@playwright/test` and `@axe-core/playwright` (no
   Playwright config or spec yet). Tests: `src/app/api/health/route.test.ts` (`GET()` answers 200 with
   `{ status: "ok" }`) and `src/lib/logger.test.ts` (a logger on a memory stream writes one JSON line with
   `app: "mawsim"`, the given `event` and the level).
