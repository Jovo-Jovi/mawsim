### Design specification

- States: `home-ar` · `home-en` · `guide-en` · `about-ar`
- Criteria: `UA-01` · `UA-02` · `UA-03` · `UA-04` · `UA-07` · `UA-08` · `UA-11` · `UA-12` · `UA-17`

The page ground stays `--color-bg`; the texture is a faint weave under it, felt more than seen. Today `content/photos.json` is
`[]`, so every capture shows the **pattern** variant (an SVG drawn in code); the image variant is built, tested with a
fixture row, and used as soon as the owner's `texture` row exists (T17).

1. **Tokens** (`tokens.css`, the only file with raw values), exactly the names and values of `DESIGN_SYSTEM.md` §2:
   `--dur-reveal` 560ms, `--reveal-rise` 1rem, `--reveal-stagger` 60ms, `--zoom-photo` 1.05, `--tilt-card` 1.5deg,
   `--glow-ring-opacity` 0.55, `--glow-ring-spread` 0.5rem, `--scene-turn` 48s, `--texture-opacity` 0.08,
   `--texture-tile` 12rem, and `--texture-ink` (`#1F2A22` in light, `#F3EBDD` in the dark block). Nothing else changes in the file.
2. **`MarketTexture`** (`src/modules/produce/MarketTexture.tsx` + `.module.css`, exported from `index.ts`). A server
   component taking `photo: ProducePhotoRow | undefined`. It renders one `aria-hidden="true"` wrapper, `position:
   absolute`, filling its band, `pointer-events: none`, `opacity: var(--texture-opacity)`, behind content (the band has
   `position: relative; isolation: isolate`, the content sits above). With a photo: `next/image` with `fill`,
   `alt=""`, `sizes="100vw"`, lazy, `object-fit: cover`. Without: an inline SVG pattern (`<pattern>` of a woven grid of
   hairline strokes in `var(--texture-ink)`, tile `var(--texture-tile)`), no external file. No `"use client"`, no
   animation, no text, not focusable, identical in `ltr` and `rtl`. Logical properties only.
3. **Where.** Behind: the home hero (the whole `Hero` band), the home "in season this month" heading band, the guide header
   band (`h1`, month scroller, chips), the about header band (`h1`). A band is a wrapper element that already exists or
   is added around those elements; the rest of the layout and every size stay as today, so layout shift is 0. Never
   behind a card's text, a body paragraph, the storage tip, the sample-data notice or the credits. The about page's
   body sections get no texture.
4. **Contrast.** `DESIGN_SYSTEM.md` §2 states the worst case at 8%. The test reads `tokens.css` and asserts
   `--texture-opacity: 0.08` and no other value of it anywhere in `src`.
