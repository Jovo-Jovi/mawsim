### Design specification

- States: `guide-months-ar` · `guide-months-en` · `guide-month-focus-ar`
- Criteria: `UA-01` · `UA-02` · `UA-03` · `UA-04` · `UA-05` · `UA-06` · `UA-07` · `UA-09` · `UA-10` · `UA-11` · `UA-13` · `UA-14` · `UA-15` · `UA-18`

`MonthScroller` is the first control under the `h1` and above the `KindChips`: the guide's order becomes `h1`, `MonthScroller`,
`KindChips`, `CardGrid`, `SampleDataNotice`. Pick a month, then a kind. Arabic is judged first; English is its LTR adaptation.

**Markup.** A `nav` labelled `guide.months`, carrying the attribute `data-month-scroller`, holding an `<ol>` of twelve links, January
first from the inline start (right to left in Arabic). Each link's text is `months.N` (the full name, both locales) and its href is
`guideHref(locale, N, kind)`, so `kind` is kept. The selected month, `selectedMonth`, carries `aria-current="true"` and the one filled
pill (`--color-primary` ground, `--color-on-primary` text); the other eleven are `--color-primary` text with no box. This
month (`currentMonth`) carries a small `--color-highlight` dot and the visually hidden text `guide.thisMonth`, inside its own link; the
dot is decoration, never the only signal (UA-13). If the dot has less than 3:1 against the ground it sits on, give it a
`--color-ink` hairline ring. Every link is at least `--target-min` in both dimensions (UA-14).

**Layout.** Below 64rem the list is one row that scrolls inline, with CSS scroll-snap (`scroll-snap-type: x proximity`,
`scroll-snap-align: start`, `overscroll-behavior-inline: contain`) and no hidden scrollbar. At 64rem and above all twelve are visible
at once in twelve equal tracks, nothing scrolls. The page itself never scrolls sideways (UA-15); only this list scrolls inline.
Spacing from `--space-*`. Logical properties only.

**Selected month in view on load, without script.** The selected link sets `scroll-initial-target: nearest`, so the browser shows it
on first paint with no layout shift and no script. Only the list scrolls: `window.scrollY` stays 0 on load. Both `month=12` captures
prove it (December sits at the far end of the list in either direction).

**Behaviour.** Hover changes colour only; `focus-visible` shows the 2px `--color-primary` ring with a 2px offset (§9). No
animation and no transition (`transition-property: none`, as the chips do); T11 owns motion. Both themes: every text pair passes
§2 contrast; `--color-on-primary` on `--color-primary` at least 7:1.
