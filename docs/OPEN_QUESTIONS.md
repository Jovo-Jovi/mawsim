Which licensed photographs will you add, and when? Mawsim needs 11: one hero (at least 1600 px wide) and one per produce (at least 1200 px wide), each with a commercial-use licence or written permission recorded as a row in `content/photos.json` (`docs/CONTENT_MODEL.md` §5). Pinterest pins carry no licence, so an image found there needs its owner's licence first. Until a file lands, its frame shows the designed fallback.
